# 有证据的工作与决策习惯

下表是具体工作取舍，不能推导为心理诊断或普遍人格。

| 取舍 | 来源与范围 | 执行方式 |
| --- | --- | --- |
| 希望助手直接推进，减少重复解释和人工中转 | 本聊天反复重连的纠正；InstaBox 历史接入纠正 | 先查已有成果与接入，再让用户补确实缺失的信息 |
| 重视能否实际完成，而不是只说可行 | 群聊读写回执、下载归档、原机证据等历史 | 以实际读回、文件与验收记录报告完成 |
| 对读取成本敏感 | 2026-10-29 明确询问垃圾记忆与周复盘 Token | 增量扫描，短入口，按项目取细节 |
| 可要求先方案后代码 | BTC 5分钟回测任务书的明确要求 | 在该类明确任务中执行，不扩大成所有任务都必须先审批 |
| 能在证据不足或收益不值得时停止某项尝试 | NONCE 旧题停止与下一轮截止条件 | 遵守该任务停止条件，不自动重开挑战 |
| 希望多 Agent 真正共享工作结果 | 三人群聊、InstaBox 和本知识库 | 共享带来源的成果；不将背景共享等同于自动在线 |

未获明确确认的“冲动、缺乏坚持、普遍急躁”等判断不进入记忆。其他 Agent 的人格评价只能作为带来源的观察，不能升为用户事实。
