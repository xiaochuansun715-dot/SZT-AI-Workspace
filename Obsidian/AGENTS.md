# 本知识库协作约定

先读 AI_START.md 与 01_Profile/Preferences.md。
在当前用户授权范围内维护 Markdown；不得上传密码、令牌、私钥、助记词、会话或原始凭据配置。
对项目事实标明来源日期、记录日期、证据与未知项。创建日期不等于实时核验日期。
当前明确指令优先于历史偏好。保留纠错与取代关系，不把失败、未验证或过期结果写成成功。
修改前读取现有文件并检查并发变化；不得覆盖其他助手的修改。
修改后更新 04_Log/Changelog.md，并运行 python tools/build_context.py 更新 AI_CONTEXT.md。
首版仅是用户选择项目与偏好的摘要，不是全部聊天记录，也不是完整资产台账。
